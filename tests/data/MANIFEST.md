# Contract fixtures

`evaluations/v1` through `v5` are hand-authored minimal evaluation directories
created on 1 November 2026 from the documented format contracts, without invoking
alphatonic. They are compatibility examples, not historical writer captures.
The first row represents three perfectly associated pairs; the second has no
mature label. Formats 1–3 use CSV, 4–5 gzip with fixed mtime. Optional analyses
are absent. Format 1 must restore raw return targets; retired mode is ignored.
Expected values are specified in the tests and must not be regenerated by a writer.

`studies/v1` is a hand-authored record with omitted family (defaults to signal),
an extra field (ignored), and one independently specified metric of 0.5.
`exports/scalars.json` specifies strict scalar JSON types independently of the exporter.
